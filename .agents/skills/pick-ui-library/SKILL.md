# Pick UI Library (Emil Kowalski)

## Philosophy
- Prefer headless, unstyled primitives (Radix UI, React Aria) or pure bespoke CSS over rigid, heavily opinionated libraries (MUI, Ant Design).
- Total CSS control is non-negotiable for craft details: custom cubic-bezier curves, active scale physics, refined dark mode neutrals, and custom borders.
- Keep components focused, accessible, and lightweight.
